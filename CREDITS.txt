ccminer-legacy -- credits & donation
====================================

Lineage
-------
Originally based on Christian Buchner's and Christian H.'s CUDA project
(inactive on GitHub since 2014), then:

    tpruvot/ccminer  ->  Kudaraidee/ccminer-kudaraidee  ->  tpfuemp/ccminer-tpfuemp
        ->  tpfuemp/ccminer-legacy (this fork)

ccminer-tpfuemp targets modern NVIDIA hardware on CUDA 11.8. This fork keeps
its code base running on older GPUs (sm_30 Kepler .. sm_52 Maxwell) with
CUDA 8, VS2015 on Windows and GCC 5 on Linux.

Kernel / code contributors
---------------------------
Includes kernels and work from: lenis0012, tpruvot, alexis78, djm34, djEzo,
tsiv, and krnlx, plus the many contributors to the upstream ccminer projects.
